# Languages and the site's words

Blysis ships in twelve languages. Which of them your visitors can read, and every word the site says in them, is yours to change from the panel.

## The languages your site offers

**Admin > Languages** lists every language with how much of the site it holds. Tick the ones visitors may choose and mark the one the site opens in; setup chose that one for you, and you can change it here.

- A visitor is shown the language they picked before, or the one their browser asks for if your site offers it, and otherwise the site's own.
- A link into a language you do not offer opens the same page in the site's language.
- The footer's language picker, the sitemap and search engines see only the languages you offer.
- The panel itself keeps every language, so each admin can still read it in theirs.

## Changing what the site says

**Admin > Translations** holds every string the site says: core's, each module's and the active theme's, one line each, with what visitors read in each language. Click into a string to change it. Your words are kept over the original through updates and theme changes.

- **History** on a string lists every change made to it, and **Undo** beside one puts back what the string said before it. Putting a version back is a change of its own, so it can be undone too.
- **Replace a word** changes one word in every string that says it, one language at a time. You see each change before anything is written and keep only the ones you want.
- A string that names a live value shows what visitors read now; see [Live values in your text](./modules-and-themes.md#live-values-in-your-text).

## After an update, or a change in one language

Two filters under **Show** find the strings that want your eye:

- **Only what an update changed**: an update shipped a new original under one of your edits. The string shows the original then and now; choose **Keep mine** or **Use the new one**.
- **Only what awaits translation**: the string was changed in another language after this one was written. Rewrite it, or mark it **Still right**.

## Moving your words to another site

**Export** on the translations screen saves every string your site has changed as one file. **Import** on another site, or on this one after a reinstall, shows each string the file would change, as the site says it now and as the file says it, and writes only the ones you keep. Strings the site does not have, and strings that already say the same, are left alone. An imported change can be taken back like any other.
